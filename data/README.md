# Dataset

Place your supplied `Telco_customer_churn.xlsx` in `data/raw/` before running the project. The raw workbook is intentionally excluded from Git.

This project requires the expanded IBM Cognos Telco sample with **7,043 rows and 33 columns**, including `Churn Value`, `Churn Label` and `Tenure Months`. The popular 21-column Kaggle CSV has different names and is not a drop-in replacement.

Source context and field definitions: [IBM Telco customer churn sample](https://community.ibm.com/community/user/blogs/steven-macko/2019/07/11/telco-customer-churn-1113?hlmlt=VT).

The supplied file matches this sample's structure. Its exact distribution source and redistribution terms were not supplied. Check those terms before uploading the workbook publicly. The repository's code license, if added, does not license IBM's data.

The sample describes a fictional company. It is suitable for a learning project, but it does not establish performance on a real telecom customer base. The accompanying experiment JSON records the workbook's SHA-256 so a local rerun can be checked against the original run.
